# Точность составных квадратур на [0, 1]

Это малый детерминированный численный эксперимент: исследуются функции x² и x⁴ на равномерных сетках с n = 10, 20, 40, 80 подынтервалами. Точные интегралы получены по первообразной x^(p+1)/(p+1): соответственно 1/3 и 1/5.

Метод trapezoid использует половинные веса на концах и единичные внутри, умножая сумму на h = 1/n. Метод simpson при чётном n использует веса 1, 4, 2, …, 4, 1 и множитель h/3. Оба исходных файла изучены; генератор исполняет функции integrate без запуска main, чтобы не переписывать входные файлы.

Для независимой проверки все узлы и квадратурные суммы вычислены заново в точной рациональной арифметике Fraction. Проверены все 16 полученных строк: оценки, точные ссылки, абсолютные ошибки и совпадение с исполненными функциями. Точные знаковые ошибки Q−I для trapezoid равны 1/(6n²) для x² и 1/(3n²)−1/(30n⁴) для x⁴. Для simpson они равны нулю для x² и 2/(15n⁴) для x⁴. Все ненулевые ошибки здесь положительны. Рациональные суммы точно совпали с этими формулами; отклонения полученных чисел проверены с допуском 8 ulp значения интеграла.

| Метод и функция | E(10)/E(20) | E(20)/E(40) | E(40)/E(80) |
|---|---:|---:|---:|
| trapezoid_x2 | 4.0000000000 | 4.0000000000 | 4.0000000000 |
| trapezoid_x4 | 3.9969992498 | 3.9992499531 | 3.9998124971 |
| simpson_x4 | 15.9999999994 | 15.9999999899 | 15.9999997783 |

При удвоении n ошибки trapezoid уменьшаются примерно в 4 раза: наблюдаемый порядок близок к 2. Для simpson на x⁴ уменьшение примерно в 16 раз соответствует порядку 4. Небольшое отклонение отношений trapezoid для x⁴ от 4 объясняется членом n⁻⁴; отношения стремятся к 4.

Формула Симпсона точна для многочленов степени до трёх, поэтому для x² ошибка дискретизации строго равна нулю. В полученных данных абсолютная ошибка относительно float(1/3) составляет 1.1102230246251565e-16 на всех сетках: это округление двоичной арифметики, а не сходимость четвёртого порядка. Само число 1/3 также не представимо точно в float. В verification.json дополнительно записана ошибка относительно рационального интеграла.

На errors.svg показаны три серии с логарифмической шкалой ошибки по основанию 10 и логарифмическим расположением n по основанию 2. Серия simpson x² исключена как близкая к нулю и определяемая округлением; log(0) нигде не вычисляется. В comparison.csv сохранены именно полученные числовые значения без замены независимыми расчётами. SHA256 исходных байтов result.json и подробности проверок находятся в verification.json. Выводы относятся к этим двум полиномам и четырём сеткам, а не ко всем возможным функциям.
