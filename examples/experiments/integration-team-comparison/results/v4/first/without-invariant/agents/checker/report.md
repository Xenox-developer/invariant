# Точность численного интегрирования

Это малый детерминированный численный эксперимент: интегрируются x**2 и x**4 на [0,1] при n = 10, 20, 40, 80 равных подынтервалах. Точные эталоны следуют из первообразной x**(p+1)/(p+1): 1/3 и 1/5.

Составная формула трапеций использует веса 1/2 на концах и 1 внутри с множителем h=1/n. Составная формула Симпсона использует веса 1,4,2,…,4,1 с множителем h/3; все выбранные n чётны. Полученные файлы не изменялись: обе реализации изучены и выполнены через integrate, без запуска записывающих main. Все 16 оценок совпали с их исходными значениями. CSV сохраняет полученные числа, включая ошибки.

Независимая проверка выполнена точными рациональными суммами Fraction на сетке i/n. Для ошибки Q−I формулы трапеций дают 1/(6n²) для x**2 и 1/(3n²)−1/(30n⁴) для x**4. Они следуют из сумм степеней (или формулы Эйлера–Маклорена, которая здесь обрывается). Для Симпсона S_n=(4T_n−T_(n/2))/3: член n⁻² сокращается, поэтому ошибки равны 0 и 2/(15n⁴). Рациональные суммы точно совпали с этими формулами во всех случаях. Допуск для округления оценок составил восемь ulp; отдельно проверены эталоны и вычитания ошибок.

Измеренные отношения E(n)/E(2n):

| Серия | 10→20 | 20→40 | 40→80 |
|---|---:|---:|---:|
| trapezoid_x2 | 4.0000000000 | 4.0000000000 | 4.0000000000 |
| trapezoid_x4 | 3.9969992498 | 3.9992499531 | 3.9998124971 |
| simpson_x4 | 15.9999999999 | 15.9999999893 | 15.9999999147 |

Отношения около 4 подтверждают второй порядок трапеций; около 16 — четвёртый порядок Симпсона для x**4. Соответствующие наблюдаемые порядки log2(E(n)/E(2n)) равны:
- trapezoid_x2: 2.00000000, 2.00000000, 2.00000000
- trapezoid_x4: 1.99891730, 1.99972945, 1.99993237
- simpson_x4: 4.00000000, 4.00000000, 3.99999999

Для x**2 Симпсон математически точен. Во всех четырёх полученных строках ошибка относительно float(1/3) равна 5.551115123125783e-17 (одна ulp): это округление двоичной арифметики, а не ошибка квадратуры. Сам float(1/3) тоже приближён; verification.json дополнительно содержит ошибку относительно точной рациональной дроби. Отношения этих почти нулевых ошибок не характеризуют порядок метода.

На errors.svg показаны три серии с положительными ошибками; ось ошибок логарифмическая (log10), ось n — log2. Серия simpson x**2 опущена, поскольку находится на уровне округления; логарифм нуля не вычисляется. Выводы относятся к этим полиномам и четырём сеткам.

Воспроизведение: `python3 -B build_report.py --inputs inputs --output .`. Использована только стандартная библиотека Python. Контрольные SHA256 вычислены по исходным байтам result.json и записаны в verification.json.
